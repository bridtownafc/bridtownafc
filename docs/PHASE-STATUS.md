## Local application foundation

**Status:** Phase 2 complete locally.

The repository now contains an Astro and TypeScript application with a responsive red, white and black design system and seven initial routes: Home, Match Centre, Team, News, Commercial, Club and Contact. The application passes Astro type checking and a production build.

The current content is an honest foundation: unconfirmed fixture, squad, contact and historical details remain clearly marked rather than invented. Commercial packages use the club's agreed current examples but remain structured for later CMS management.
